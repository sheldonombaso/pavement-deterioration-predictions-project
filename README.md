# PAVEMENT DETERIORATION PREDICTIONS ON KENYAN ROADS USING THE XGBOOST MODEL 

Welcome to the XGBoost model repository!

This project demonstates how Extreme Gradient Boosting (XGBOOST) works on predictions on categorical data. The model expresses high accuracy in predictions of the pavement deterioration rate for the roads in Kenya. The model uses International Roughness index (IRI) which is standardized measure or Road Roughness. IRI is established through sophisticated scientific tools called the Dynamic Response Intelligent Monitoring System (DRIMS) that uses lasers and sensors to determine surface unevenness. This project demostrates comprehensive data warehosuing and analytics solution, from building data warehouse to generating actionable insights. This is Designed as a portfolio project where it highlights industry best practices in data engineering and analytics.

## Project Requirements
### Building the Data Warehouse (Data Engineering)

#### Objective
To predict pavement deterioration using the International Roughness index (IRI)


#### Specification

- **Data Sources** : Import IRI data from sources (LabVIEW File & Excel)
- **Data Quality** : Clean and resolve data quality issus before Analysis
- **Data Intergration** : Combine both sources into single, user friendly data model designed for analytical queries
- **Scope** : Focus on latest dataset only; Historical data in not required and should not be manipulated(as-is)
- **Documentation** : Provide clear documentation of the data model to support both technical and non-technical stakeholders & Analytic teams.
